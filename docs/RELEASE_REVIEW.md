# Проверка перед релизом — 16 сентября 2026

Проверены хранение настроек и пароля, нативные обработчики команд, жизненный цикл блокировки, WebView2, обновления, импорт медиатеки, рендер, диагностика и сборка. Найденные ниже дефекты исправлены. Это проверка исходников и регрессионных сценариев на текущем ПК, а не гарантия отсутствия любых ошибок или независимый аудит безопасности.

## Найдено и исправлено

| Приоритет | Проблема | Результат |
|---|---|---|
| Высокий | Проверочный хеш пароля находился в INI и попадал в экспорт | PBKDF2-HMAC-SHA256, 600 000 итераций; хеш и политика блокировки внутри DPAPI. Права файла: текущий пользователь и SYSTEM. Экспорт/пресеты без секретов, импорт сохраняет местную защиту |
| Высокий | Смена/удаление пароля и отключение запроса не требовали текущего пароля | Проверка в нативном обработчике, ограниченное по времени одноразовое разрешение, пауза после пяти ошибок |
| Высокий | Escape, закрытие поверхности, горячая клавиша и открытие настроек могли закрывать заставку до включения экрана пароля | Единая проверка необходимости пароля при возврате. Сообщение разблокировки принимается только после успешной проверки |
| Высокий | Отказ окна пароля возвращал рабочий стол | Запрос блокировки Windows; поверхности сохраняются до уведомления Windows о блокировке сеанса |
| Высокий | Не было ограничения навигации и проверки источника сообщений WebView2 | Разрешён только исходный встроенный документ, остальные переходы, окна и загрузки запрещены; CSP ограничивает ресурсы; источник сообщений проверяется |
| Высокий | Названия пресетов, строка поиска и версия обновления могли интерпретироваться как HTML | Текстовые DOM-узлы и экранирование. Проверены специально подготовленные строки с HTML |
| Средний | Число запросов обновления было неограниченным, результат передавался указателем в оконном сообщении | Один запрос за раз, результат принадлежит общему объекту с mutex; уведомление не содержит указателей, завершение окна учтено |
| Средний | Вложенный `author.html_url` мог считаться ссылкой релиза; ответ загружался без надёжной границы | Проверка полного JSON, ограничение объёма и глубины, обработка Unicode, верхний уровень полей, проверка репозитория, запрет редиректов |
| Средний | Некорректные соли/хеши и чрезмерная стоимость KDF принимались парсером | Фиксированные размеры соли/хеша, строгий base64, ограничение длины и диапазона итераций |
| Средний | Ошибки файловой системы и большой ID могли приводить к сбоям медиатеки | Неисключающие проверки файлов, корректное перечисление, поиск свободного ID без переполнения |
| Низкий | Повторялись лишние копии чувствительных строк; оставались тестовые элементы интерфейса | Очистка временных нативных буферов, удаление DEV TEST и глобальных тестовых функций страниц |
| Низкий | Документация описывала старые часы, качество и удаление пароля без проверки | README, RELEASE_NOTES и SECURITY приведены к фактическому поведению |
| Средний | Для загрузки можно было случайно взять старый запущенный EXE из dist или папку с тестовыми данными | ZIP из проверенного build/Release и явного списка файлов, внутренний SHA256SUMS и контрольная сумма ZIP |

Дополнительно исправлен ключ кеша часов: AM/PM корректно обновляется при скачке времени на 12 часов. Невалидные числовые/логические сообщения настроек отклоняются. При сбое встроенного браузера очередь сообщений ограничена и рендер превью останавливается.

## Выполненные проверки

- Release MSVC x64, сборка через корневой `build.bat`.
- 12 наборов CTest: core, wake, settings, lock, cursor, bridge, update, WebView runtime, performance, media, native security flow, WebView confinement.
- DPAPI: чтение своей записью, разные шифротексты, повреждение данных, миграция, отсутствие открытого хеша, DACL, атомарная замена при заблокированном файле, экспорт и импорт.
- Нативная авторизация: неверный пароль, cooldown, истёкшее/повторно использованное разрешение, смена/удаление, поддельное сообщение разблокировки, Escape/закрытие/горячая клавиша/трей.
- Реальный WebView2: исходная страница работает, переходы на внешний URL и about:blank блокируются, сетевой fetch запрещён, сообщения внедрённого фрейма не доходят.
- Три набора Playwright: интерфейс и пароль; защита от случайного пробуждения; производительность и медиатека. Ошибок JavaScript в проверенных сценариях нет.
- Реальный MP4 в WebView2: декодирование кадров и переход к неподвижному кадру deep rest.
- Smoke в обычном режиме и с `--software`: 96 различных кадров, 12 движущихся сцен, 3 стиля часов, изменение размера, 3 монитора, нативное полноэкранное разрешение.
- Визуально проверен диалог подтверждения текущего пароля.
- ZIP проверен после сборки: ровно 8 ожидаемых файлов; все 7 сумм содержимого и внешняя сумма ZIP совпали. EXE внутри ZIP, в корне, build/Release и dist идентичны. SHA-256 EXE: `334143bbff1bbcf5dc20a7edc9ebb1c5546d7e261f99ba7e5997f8b436d029bc`.

WebView2 не запускал дочерние процессы в ограниченной среде инструмента. Нативные интеграционные проверки выполнены вне этих ограничений с отдельными временными данными. Настройки и пароль пользователя для тестов не использовались.

## Практические ограничения

- **Это не защищённый рабочий стол Windows.** Администратор или процесс под тем же пользователем может завершить приложение, прочитать память или заменить/удалить целиком файл настроек. DPAPI не меняет эту границу. Для защиты сеанса используйте Win+L.
- Реальное автоматическое включение Windows lock при отказе UI не проверялось до конца на пользовательском сеансе: такой тест заблокировал бы текущий рабочий стол. Проверен код запроса и ожидания подтверждения; сценарии обычной блокировки покрыты нативными тестами.
- EXE не подписан Authenticode. SHA-256 подтверждает совпадение файлов с доверенной контрольной суммой, а не личность издателя.
- Не проводились проверки на всех GPU, Windows-версиях и кодеках. Большие видео копируются синхронно и могут временно задержать интерфейс; декодирование зависит от WebView2. Приложение не ограничивает нагрузку чужих процессов.

Техническое описание защиты, миграции и восстановления: [SECURITY.md](../SECURITY.md). Для распространения предназначен `releases/Hibernation-1.0.0-windows-x64.zip`; исходники, временные настройки, тестовые видео, профили браузера и отладочные EXE в него не входят.
