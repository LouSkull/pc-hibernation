// what it does

A real screensaver, rebuilt from scratch.

Everything is one page and one process. Scenes run on the GPU; the whole interface, the lock screen and the tray panel are drawn in WebView2 — so it looks the same everywhere and stays tiny.

Twelve living scenes

Silk, aurora, lava, caustics, neon — real Direct3D 11 shaders, eight palettes, and live-rendered thumbnails.

Your own videos

Drop in an MP4, WebM, GIF or WebP and it loops, muted, as the screensaver — kept in your own library.

Password lock

Ask for a password before the desktop returns. PBKDF2-HMAC-SHA256, salted; it unlocks the moment you finish typing — no Enter.

Custom cursor

An osu!-style Orbit ring, or bring your own .png / .cur / .ani. Optional trail, crisp on HiDPI.

On-screen clock

Three faces, 12/24-hour, seconds, weight and colour — chosen in a popup with a live preview.

Quiet on the machine

Economy profiles, adaptive FPS, deep rest and Windows EcoQoS — with a diagnostics graph if you want the numbers.

Start with Windows

Opt-in autostart for just your account, with a choice of opening the window or slipping straight to the tray.

Built-in updates

One button checks GitHub for a newer release and offers the download. It's the only time the app touches the network.

Tray panel & presets

Right-click the tray for a small styled panel, search every setting, and save or share looks as plain preset files.

// honest about limits

A lock, not a login.

Real hashing.

600,000-round PBKDF2, per-password salt, constant-time compare, sealed with DPAPI for your Windows account. The plain password never touches disk.

Mouse-proof screen.

No cursor, clicks and scrolling do nothing, focus stays in the field. Idle a while and the prompt clears itself.

Fails open.

If the lock can't render it hands back the desktop rather than trapping you out.

It is a screensaver lock, not a replacement for signing in. Ctrl+Alt+Del and Win+L stay Windows' own, and Ctrl+Shift+Esc is left free on purpose. Forgot the password? Open Security and remove it.
